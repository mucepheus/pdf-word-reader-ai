# PDF & Word Reader AI

This project is a simple program that can read PDF and Word files, extract the text, and generate answers based on the content.  
It uses Python libraries for document parsing and an AI model for text-based Q&A.

## Features
- Read `.pdf` and `.docx` files
- Extract and clean the text
- Ask questions and get answers from the document content
- Easy to expand with more file types
